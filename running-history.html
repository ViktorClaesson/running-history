Running history — every run, on a log scale

One bar per day, height is that day’s own distance on a logarithmic axis — 5→10 km is the same step as 10→20, so one very long run can’t flatten every short one and short runs stay readable against each other. A day with no run gets a tiny grey stub below the axis floor rather than nothing at all, which also keeps it easy to hover and click. The colour is not about that one run: it says which rolling distance-per-week window is on top that day — the shortest one winning is the strongest reading — so the answer is “is my training trending up” rather than “was this run long enough”. Rolling weekly volume has moved to its own panel just below, in the same four colours.

Double-click, or press r, to go back to the default view, the longest window ending on the most recent day. Click a day to pin its numbers in the readout above; click it again, or press t or Esc, to release. The coloured dots along the top of each panel mark where each window reaches back to — filled from the day under the pointer, hollow from the pinned one, and a chevron at the left edge for a window that reaches back past what's drawn.
